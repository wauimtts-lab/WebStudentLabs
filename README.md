# Лабораторная работа «Основы JavaScript: функции»

Дисциплина «Веб-программирование».

## Цель работы

Получить практические навыки написания функций на JavaScript: циклов и рекурсии, работы с числами и массивами, функций, возвращающих функции, и рекурсивного обхода объектов. Освоить проверку решения автоматическими тестами.

## Состав проекта

| Файл | Назначение |
|---|---|
| `core.js` | заготовки десяти функций с условиями задач — **здесь пишется решение** |
| `core.spec.js` | автоматические тесты (Mocha); **не изменяется** |
| `package.json` | описание проекта и команда запуска тестов |

## Подготовка

1. Установите Node.js (версия 18.18 или новее): https://nodejs.org. Проверка установки: `node -v`.
2. Откройте папку проекта в терминале и установите зависимости:

   ```
   npm install
   ```

3. Запустите тесты:

   ```
   npm test
   ```

   До начала работы все 16 тестов завершаются ошибкой — это ожидаемо. По мере выполнения заданий число пройденных тестов растёт.

## Задания

Полные условия и примеры приведены в комментариях к каждой функции в файле `core.js`.

| № | Функция | Что требуется |
|---|---|---|
| 1 | `isInteger(n)` | проверить, является ли число целым |
| 2 | `even()` | вернуть массив чётных чисел от 2 до 20 |
| 3 | `sumTo(n)` | сумма чисел от 1 до n с помощью **цикла** |
| 4 | `recSumTo(n)` | сумма чисел от 1 до n с помощью **рекурсии** |
| 5 | `factorial(n)` | факториал числа n |
| 6 | `isBinary(n)` | проверить, является ли число степенью двойки |
| 7 | `fibonacci(n)` | n-е число Фибоначчи |
| 8 | `getOperationFn(initialValue, operatorFn)` | функция, накапливающая результат операции между вызовами |
| 9 | `sequence(start, step)` | генератор арифметической прогрессии |
| 10 | `deepEqual(a, b)` | глубокое сравнение двух значений |

Задания 8 и 9 основаны на замыканиях: возвращаемая функция должна сохранять своё состояние между вызовами. Задание 10 требует рекурсивного обхода свойств объектов и массивов.

## Требования

- Не изменяйте имена функций, их параметры и блок `module.exports` в конце файла `core.js`.
- Не изменяйте файл `core.spec.js`.
- Не используйте сторонние библиотеки.
- В задании 3 используйте цикл, в задании 4 — рекурсию.
- Код должен работать в строгом режиме.
